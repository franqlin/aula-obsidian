O Zettelkasten é um método de organização de notas que se baseia em conexões entre ideias, e no Obsidian, ele pode ser implementado de várias maneiras. A configuração básica de pastas pode variar conforme as necessidades do usuário, mas aqui está uma estrutura comum que você pode seguir:



1. **Inbox**
   - **Descrição**: Uma pasta para capturar rapidamente ideias, notas soltas ou referências que ainda não foram processadas.
   - **Uso**: Aqui você pode armazenar notas que ainda precisam ser revisadas, categorizadas ou conectadas a outras notas.

2. **Notas Permanentes**
   - **Descrição**: O coração do seu Zettelkasten, onde as notas bem elaboradas e interconectadas são armazenadas.
   - **Uso**: Após processar uma nota da Inbox, ela deve ser movida para cá e conectada a outras notas relevantes.

3. **Referências**
   - **Descrição**: Uma pasta para armazenar notas de referência, como citações, resumos de livros, artigos ou fontes externas.
   - **Uso**: Essas notas geralmente são mais descritivas e servem como base para criar notas permanentes.

4. **Templates**
   - **Descrição**: Uma pasta para armazenar modelos de notas que você usa com frequência.
   - **Uso**: Aqui você pode guardar templates para diferentes tipos de notas, como resumos, revisões ou notas de leitura.

5. **Projetos**
   - **Descrição**: Uma pasta para notas relacionadas a projetos específicos.
   - **Uso**: Use esta pasta para organizar notas que estão diretamente relacionadas a um projeto em andamento.

6. **Arquivo**
   - **Descrição**: Uma pasta para notas que não estão mais ativas, mas que você deseja manter para referência futura.
   - **Uso**: Quando uma nota ou projeto é concluído, ele pode ser movido para o Arquivo.

### Exemplo de Uso

- **Inbox**: Captura rápida de uma ideia durante uma leitura.
- **Notas Permanentes**: Desenvolvimento da ideia com conexões a outras notas.
- **Referências**: Armazenamento de citações ou resumos de livros relacionados.
- **Templates**: Uso de um modelo para criar uma nova nota de leitura.
- **Projetos**: Organização de notas para um artigo que você está escrevendo.
- **Arquivo**: Movimentação de notas de projetos concluídos.

Essa estrutura é flexível e pode ser adaptada conforme suas necessidades. O importante é manter uma organização que facilite a conexão e a recuperação de ideias, que é o cerne do método Zettelkasten.
